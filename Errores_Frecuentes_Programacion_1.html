Errores frecuentes de programación

Esta guía recoge errores que pueden aparecer repetidamente a lo largo del curso.

El objetivo no es memorizar soluciones, sino aprender a reconocer patrones de error que vuelven a aparecer cuando los problemas se hacen más complejos.

Antes de modificar el código, intenta siempre responder:

  1. ¿Qué debería hacer el programa?
  2. ¿Qué está haciendo realmente?
  3. ¿Qué valores tienen mis variables?
  4. ¿De qué tipo son?
  5. ¿Qué condición o cálculo no representa correctamente el problema?
  6. ¿Qué caso de test permite comprobar mi hipótesis?

1. Tipos y representación de datos

Error frecuente

Olvidar que input() devuelve un str.

edat = input()
resultat = 2026 - edat

Aunque el usuario escriba:

2000

Python recibe:

"2000"

No:

2000

Corrección

edat = int(input())
resultat = 2026 - edat

Este problema puede reaparecer más adelante

Por ejemplo:

opcio = input()

if opcio == 1:
    ...

Aquí:

opcio == "1"

pero estamos comparándolo con:

1

Pregunta para depurar

¿Qué valor tiene la variable y de qué tipo es?

2. Expresiones aritméticas y traducción de fórmulas

Error frecuente

Conocer las operaciones, pero traducir incorrectamente la fórmula.

Por ejemplo, queremos calcular:

1 + 4 − x 3(x + 3)

Una traducción incorrecta podría ser:

(1 + 4 - x) / 3 * (x + 3)

Python interpreta las operaciones en un orden determinado.

La expresión correcta sería:

(1 + 4 - x) / (3 * (x + 3))

Antes de programar

Escribe primero la fórmula con paréntesis.

Después tradúcela a Python.

Pregunta para depurar

¿Mi expresión Python representa exactamente la fórmula del enunciado?

3. Composición booleana

Error frecuente

Comprobar por separado condiciones que realmente forman una única condición lógica.

Queremos:

x e y deben estar entre 0 y 10.

Una forma problemática:

if x <= 0:
    print(False)

if x >= 10:
    print(False)

if y <= 0:
    print(False)

if y >= 10:
    print(False)
else:
    print(True)

El else pertenece únicamente al último if.

Primero construimos la condición

x está dentro
AND
y está dentro

Después:

x > 0 and x < 10 and y > 0 and y < 10

Y finalmente:

if x > 0 and x < 10 and y > 0 and y < 10:
    print(True)
else:
    print(False)

Pregunta para depurar

¿Puedo escribir primero, en una sola expresión, qué significa que el caso sea verdadero?

4. Límites y casos frontera

Muchos errores aparecen exactamente en los límites.

Por ejemplo:

x > 10

no significa lo mismo que:

x >= 10

Si tenemos:

if import_final > 500:

debemos preguntarnos qué ocurre con:

499.99
500
500.01

Los mejores tests suelen estar alrededor del límite

Si el límite es 10, prueba:

9
10
11

Si el límite es 500, prueba:

499.99
500
500.01

Pregunta para depurar

¿Qué ocurre justo antes, exactamente en y justo después del límite?

5. Control condicional y selección de casos

Error frecuente

Ordenar incorrectamente condiciones que se solapan.

Por ejemplo:

if preu > 500:
    descompte = 5

elif preu > 1000:
    descompte = 10

Para:

preu = 1200

la primera condición ya es verdadera:

1200 > 500

Por tanto, Python no llega al elif.

Una posible solución

if preu > 1000:
    descompte = 10

elif preu > 500:
    descompte = 5

Pregunta para depurar

¿Puede una condición anterior capturar también los casos de una condición posterior?

6. División entera, módulo y divisibilidad

Error frecuente

Confundir eliminar cifras con extraer una cifra.

Queremos obtener la cifra de las unidades de millar de:

26477

Hacer:

26477 // 1000

produce:

26

Eso elimina las tres últimas cifras, pero todavía no hemos aislado la cifra deseada.

Necesitamos:

(26477 // 1000) % 10

Resultado:

6

Idea importante

Los operadores pueden ser correctos y, aun así, la composición de operaciones puede no resolver el problema.

Pregunta para depurar

¿Qué transformación produce cada operación y qué información me falta todavía?

7. Control del bucle: inicialización, condición y actualización

Todo bucle tiene al menos tres elementos fundamentales:

INICIALIZACIÓN
      ↓
CONDICIÓN
      ↓
ACTUALIZACIÓN

Por ejemplo:

i = 0

while i < 10:
    print(i)
    i = i + 1

Error frecuente

Olvidar actualizar la variable:

i = 0

while i < 10:
    print(i)

La condición:

i < 10

siempre continuará siendo verdadera.

Pregunta para depurar

¿Qué variable hace que el bucle avance hacia su final?

8. Contadores y acumuladores

No cumplen la misma función.

Contador

Cuenta cuántas veces ocurre algo:

comptador = 0

comptador = comptador + 1

Acumulador

Conserva un resultado parcial:

suma = 0

suma = suma + valor

Para productos suele inicializarse en:

producte = 1

no en:

producte = 0

porque:

0 × cualquier número = 0

Pregunta para depurar

¿Esta variable cuenta elementos o acumula un resultado?

9. Estado y procesamiento de secuencias

En algunos problemas necesitamos recordar información de valores anteriores.

Por ejemplo, para buscar máximo y mínimo:

maxim = primer_valor
minim = primer_valor

Después, para cada nuevo valor:

if valor > maxim:
    maxim = valor

if valor < minim:
    minim = valor

maxim y minim representan el estado actual del algoritmo.

Error frecuente

Actualizar incorrectamente una variable o perder la información acumulada.

Técnica útil

Haz una tabla:

valormáximomínimo
888
383
12123

Pregunta para depurar

¿Qué información del pasado necesito conservar para procesar el siguiente valor?

10. Centinelas y terminación

Un valor centinela indica que debemos dejar de leer datos.

Por ejemplo:

-1

puede significar:

terminar la secuencia.

Error frecuente

Procesar el centinela como si fuera un dato.

Entrada:

8
3
-1

Si hacemos:

if num < minim:
    minim = num

antes de comprobar el final, podemos terminar con:

mínimo = -1

aunque -1 no pertenece a la secuencia.

Patrón recomendado

LEER
 ↓
VALIDAR
 ↓
PROCESAR
 ↓
ACTUALIZAR
 ↓
REPETIR

Pregunta para depurar

¿El valor que acabo de leer es un dato que debo procesar o una señal para terminar?

11. Modelización y descomposición computacional

Este es uno de los errores más importantes porque aparece en muchos ejercicios diferentes.

Error frecuente

Empezar a escribir Python antes de haber diseñado la solución.

Antes del código:

ENUNCIADO
    ↓
ENTRADAS
    ↓
SALIDA
    ↓
CASOS / TRANSFORMACIONES
    ↓
TESTS
    ↓
CÓDIGO

Por ejemplo:

obtener la cifra de las centenas de 5837.

Antes de Python:

5837
 ↓
eliminar dos cifras
58
 ↓
quedarme con la última cifra
8

Después:

centenes = (nombre // 100) % 10

Pregunta para depurar

¿Puedo explicar la solución sin utilizar todavía Python?

Si no puedes hacerlo, probablemente todavía no has terminado de diseñar el algoritmo.

Una estrategia común para todos los ejercicios

Antes de pulsar Evaluate:

  1. Comprende el enunciado.
  2. Identifica input y output.
  3. Diseña el algoritmo.
  4. Identifica los tipos de las variables.
  5. Identifica condiciones y casos frontera.
  6. Si hay un bucle, identifica su estado y su condición de parada.
  7. Construye casos de test.
  8. Predice manualmente el resultado.
  9. Ejecuta.
  10. Si falla, formula una hipótesis antes de modificar el código.

La secuencia debería ser:

PREDIGO
   ↓
EJECUTO
   ↓
OBSERVO
   ↓
EXPLICO
   ↓
MODIFICO

No:

MODIFICO
   ↓
EVALUATE
   ↓
MODIFICO
   ↓
EVALUATE
   ↓
MODIFICO...

Idea final

Un error no es únicamente algo que hay que eliminar.

Un error es información sobre la diferencia entre:

lo que pensábamos que hacía el programa

y:

lo que realmente hace

Depurar consiste en encontrar y comprender esa diferencia.
